# Delete User Conversations without retention

For issues #48 and #50, User deletion is allowed with active Matches and permanently removes every Match and its entire Conversation for both participants, including both participants' messages and blocked history. We choose complete removal over retaining or anonymizing Conversations for the remaining participant or moderation, so the deletion promise has no hidden retention exception; unrelated data belonging to other Users remains. This supersedes the previous glossary promise that blocked Conversation history survives User deletion; the confirmation must explain that Matches and Conversations disappear for both participants.

The remaining participant sees the removal on their next refresh or navigation. Requests for deleted Matches or Conversations fail immediately after deletion; no real-time deletion notification is required.
